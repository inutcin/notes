Renice (изменение приоритета выполнения процесса)
===================

Пример

```bash
$sudo renice -n 1 -p 1074430
```

Результат
```
1074430 (process ID) старый приоритет 0, новый приоритет 1
```

где

- **-n 1** задание приоритета процесса (-19 - наивысший, 20-низший)
- **-p 1074430** номер процесса, которому меняем приоритет выполенения
