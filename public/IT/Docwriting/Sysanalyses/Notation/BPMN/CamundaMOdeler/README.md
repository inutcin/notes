Установка Camunda Modeler в Linux Mint 
================

Задача несложная, но имеет одну важную особенность, связанную с правами доступа. Поскольку Linux Mint основан на Ubuntu, все инструкции для Ubuntu и Debian подойдут и вам.

### 📥 Шаг 1: Скачивание

Скачайте архив для Linux со [страницы загрузок Camunda](https://stage.docs.camunda.io/docs/components/modeler/desktop-modeler/install-the-modeler/). Вам нужен файл с расширением `.tar.gz` (например, `camunda-modeler-x.x.x-linux-x64.tar.gz`) .

### 📂 Шаг 2: Распаковка и установка

Официальная документация Camunda рекомендует устанавливать приложение в системную директорию, чтобы оно было доступно всем пользователям. Откройте терминал и выполните следующие команды :

```bash
# Перейдите в директорию /usr/bin
cd /usr/bin

# Распакуйте скачанный архив (замените имя файла на актуальное)
sudo tar xvfz ~/Downloads/camunda-modeler-*.tar.gz

# Перейдите в распакованную папку
cd camunda-modeler-*

# Установите правильные права на chrome-sandbox (важный шаг для работы)
sudo chmod 4755 chrome-sandbox
```

### 🚀 Шаг 3: Создание ярлыка и запуск

Чтобы запускать приложение из любого места без указания полного пути, создайте символическую ссылку :

```bash
# Вернитесь в /usr/bin
cd /usr/bin

# Создайте ссылку на исполняемый файл
sudo ln -s camunda-modeler-*/camunda-modeler camunda-modeler
```

После этого вы сможете запускать Camunda Modeler из терминала простой командой `camunda-modeler`. Также вы можете найти его в меню приложений (если система проиндексировала ярлык) или создать собственный ярлык на рабочем столе, указав путь к исполняемому файлу.

### 📎 Дополнительно: Связывание файлов

Если вы хотите, чтобы файлы `.bpmn`, `.dmn` и другие открывались в Camunda Modeler по двойному клику, выполните скрипт регистрации из папки с приложением :

```bash
# Из папки с распакованным Modeler
./support/xdg_register.sh
```

### 💡 Небольшое замечание

Приведенная выше инструкция описывает установку в системную папку `/usr/bin` с правами `root`. Это официально рекомендованный Camunda способ, но он требует прав администратора. Если вы предпочитаете не «засорять» системные директории, вы можете просто распаковать архив в любую папку в вашем домашнем каталоге (например, `~/apps/`) и запускать исполняемый файл оттуда. Однако в этом случае шаг с изменением прав на `chrome-sandbox` все равно может потребоваться для корректной работы.
